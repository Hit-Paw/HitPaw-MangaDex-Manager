## Why HitPaw?

<div class="why-grid">

  <div class="why-card">
    <div class="icon-wrap"><img src="/icons/outline-key.svg" alt="" width="22" height="22" loading="lazy" /></div>
    <strong>Your API client, your rules</strong>
    <p>You bring your own MangaDex API client and credentials. Nothing routes through a third-party server — HitPaw talks to MangaDex directly, from your machine. No proxy, no leak.</p>
  </div>

  <div class="why-card">
    <div class="icon-wrap"><img src="/icons/outline-zap.svg" alt="" width="22" height="22" loading="lazy" /></div>
    <strong>Built for big libraries</strong>
    <p>The grid stays smooth at thousands of titles — no stutter, no pagination games. Search, filter by status/year/tag, and <code>Show All (N)</code> instantly.</p>
  </div>

  <div class="why-card">
    <div class="icon-wrap"><img src="/icons/outline-puzzle.svg" alt="" width="22" height="22" loading="lazy" /></div>
    <strong>Fits your workflow</strong>
    <p>Exports drop straight into MyAnimeList, AniList, MangaBaka, or Kitsu — validated MAL XML, AP .gz, MB JSON. No manual reformatting, no surprises.</p>
  </div>

  <div class="why-card">
    <div class="icon-wrap"><img src="/icons/outline-package.svg" alt="" width="22" height="22" loading="lazy" /></div>
    <strong>Zero install friction</strong>
    <p>One portable folder. No installer, no admin rights, no background services quietly running when you're not using it. Delete folder to uninstall.</p>
  </div>

</div>
